# SwooshMart & Grocery Delivery Performance Analysis

## Project Overview

Analyzed approximately 12,500 deliveries and 59,000 items across four SwooshMart and grocery stores in the Cincinnati market to identify opportunities to improve delivery performance.

## Key Findings

- Original items not found: 6.4%
- Deliveries at least 20 minutes late: 4.5%
- Order cancellation rate: 1.5%
- Missing items and late deliveries present the greatest improvement opportunities during peak-demand periods.

## Recommendations

- Improve item availability through recurring operational reviews with grocery partners.
- Improve delivery partner availability during peak hours using historical and forecasted demand analytics.
- Explore deferred fulfillment options for unavailable items.

## Tools

Python, pandas, Matplotlib, Seaborn, Jupyter Notebook
